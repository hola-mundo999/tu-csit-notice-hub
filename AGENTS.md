# Contribution instructions

- Do not add tool or vendor branding, generated-by footers, or assistant attribution to source files, documentation, assets, commit messages, or pull request text unless the repository owner explicitly asks for it.
- Do not add assistant or tool co-author trailers to commits. Keep commit author and committer metadata attributable to the human contributor.
- Before committing, review the commit message and changed files for unwanted attribution or branding.
